# GreenGuard AI

AI-powered counterfeit medicine detection system designed to identify
fake medicines sold under eco-friendly, ayurvedic, and organic labels.

## Problem

Counterfeit medicines can exploit consumer trust through fake
eco-friendly and natural product claims.

## Solution

GreenGuard AI uses a hybrid AI pipeline:

Package Photo
↓
OCR Extraction
↓
Trust Score Engine
↓
Genuine / Suspicious / Fake

The system also provides an offline-capable chat assistant using
RAG and local AI models.

## Features

- Medicine package image upload
- OCR-based information extraction
- Explainable trust score
- Batch number verification
- License/certification verification
- Packaging logo comparison
- Suspicious claim detection
- RAG-based medicine information retrieval
- Online/offline AI support
- Multilingual support
